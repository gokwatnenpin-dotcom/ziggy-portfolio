# Ziggy Portfolio

A personal portfolio website for Ziggy, a frontend developer and Python/security learner from Plateau State, Jos, Nigeria.

## About
This site showcases:
- my current skills and learning focus
- projects I have built and worked on
- contact and social links
- a simple collaboration/contact form

## Tech stack
- React
- Vite
- JavaScript
- TailwindCss
- Lucide icons
- Supabase

## What is on the site
- Hero section with intro and CTA buttons
- About section
- Skills section with learned and in-progress technologies
- Projects gallery
- Contact section with socials and email request form

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```
